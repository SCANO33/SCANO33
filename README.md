## 💼 Lo que hago

- **Desarrollo full stack:** sitios y aplicaciones web con Node.js, PHP, HTML, CSS y JavaScript/TypeScript
- **Backend:** lógica de servidor y conexión con bases de datos usando Node.js y PHP
- **Dashboards y BI:** modelos de datos y tableros interactivos en Power BI con medidas DAX
- **Bases de datos:** modelado y consultas SQL en PostgreSQL y MySQL para análisis y reportes
- **ETL:** limpieza, transformación y carga de datos desde distintas fuentes
- **EDA:** análisis exploratorio para encontrar patrones, anomalías y problemas de calidad en los datos
- **Modelos predictivos:** forecasting y regresión/clasificación con Scikit-Learn y XGBoost
- **Documentación y control de calidad:** validación de datos y documentación técnica de las soluciones que desarrollo
